# Contributing

Additions and corrections are welcome via pull request.

Guidelines:

- The project must be built on, or exist primarily to serve, the sing-box core or its rule-set/geodata formats. Generic multi-core tools qualify if sing-box support is first-class.
- One line per entry: `[Name](link) - What it is, factually.` No superlatives.
- Open-source entries should link the repository. Closed-source/commercial entries are allowed but must be labeled as such, and the description must state what is and isn't open.
- Keep entries within their section's existing ordering (roughly by adoption).
- Unmaintained projects stay listed only while guides still commonly reference them, and must carry a "no longer maintained" note.
- If you have any affiliation with the project you're adding, say so in the PR.
